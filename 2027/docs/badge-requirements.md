# NBA 2K27 Badge Requirements — Attribute Minimums by Tier

All badges require meeting attribute thresholds to unlock each tier. Badges with "OR" between attributes mean EITHER attribute qualifies. Badges with "AND" mean BOTH are required. For two-attribute badges the tier numbers are listed in the same order as the attributes (e.g. `85 / 86` = first attribute 85, second 86).

> Source: allthings.how (Aug 31, 2026), cross-referenced with nba2klab.com, gamerant.com, nuxgameguides.com

---

## What changed from 2K26

- **Tiers are now Bronze / Silver / Gold / Hall of Fame — four, not five.** The
  attribute-driven **Legend** tier from 2K26 is gone. There is still a "Legend"
  beyond HoF, but it comes from the **Synergy system + season progression**, not
  from attributes — so it is not a threshold you can plan a build around.
- **53 badges total** — 19 new this year, 6 removed from 2K26.
- **New sixth discipline: Physicals** (Strength / Speed / Agility / Vertical badges).
- **20 badge slots**, all open from the start, filled with **Badge Tokens** earned
  by play, drills, workouts, quests, and season/crew rewards. Hitting the attribute
  threshold makes a badge *eligible*; a token equips it.
- Height is checked **before** attributes and cannot be worked around.

## Attribute breakpoints worth planning around

The numbers that do the most work, per the source:

- **83 Three-Point Shot** — entry point for Limitless Range. Stop at 82 and you lose it entirely; Gold is 93.
- **90 vs 93 Ball Handle** — 90 gets Gold Handles for Days; 93 gets Gold Ankle Assassin. The two stopping points that matter.
- **70 Vertical** — HoF on Rise Up, Crasher, and Possession Closer all cap here. Unusually cheap for top-tier badges.
- **95 Strength** — HoF Strong Handle needs only 78 Ball Handle but 95 Strength. Suits big guards/wings ≤ 6'11.
- **84 Interior Defense** — enough for HoF Paint Patroller (but the paired Block climbs to 99).

**Tip:** On AND badges, check the cheaper attribute first — points spent past its threshold don't move the badge. Post Lockdown Gold needs 88 Interior Def but only 80 Strength.
