# NBA 2K27 Dribble Move-Types — Full Requirement Reference

Every dribble move-type in 2K27 gates on **Ball Handle (BH) + height**. This doc
covers the move-types beyond dribble-style/size-up/crossover/behind-back (those are in
`animation-requirements.md`). Use it to see what your build can equip in each category.

> Sources: lockercodes.io per-move-type requirement pages (verified Sep 3, 2026).
> Requirement data verified. Per-move "best" *rankings* are nba2klab Premium — this is
> the requirement + tiering, which tells you what's equippable and the quality band.

**The universal gate pattern** (holds across every move-type):
`≤6'4 elite guard 90–92 (Curry/Trae/Kyrie/Lillard)` · `≤6'9 wing-legal elite SGA 91 /
Harden 86` · `value 80 (CP3/Kawhi/LeBron)` · `cheap 75 (MJ/Tatum/DeRozan)` ·
`big 6'10+ = a short list per move (see the big-man summary at the bottom)`.

## 🏀 Big-Man / Point-Center summary — the ONLY signature moves at 6'10+

If you're 6'10+ (your point center), these are the *only* named signature dribble
packages you can equip per move-type. Everything else in each category is guard/wing
locked. Generic **Basic (0) / Normal (40) / Pro (70)** are always available too.

| Move-Type | Big-man package(s) | BH needed |
|-----------|--------------------|----------:|
| Crossover | Victor Wembanyama / Paolo Banchero | 68 / 75 |
| Behind-the-Back | Domantas Sabonis | 75 |
| Between-Legs Cross | Wembanyama / Paolo | 68 / 75 |
| Spin | Embiid / KAT / Jokic | 55 |
| Hesitation (+lateral) | Paolo Banchero | 75 |
| Stepback (all 3) | Joel Embiid | 55 |
| Combo Move | Wembanyama / Sengun | 68 / 55 |
| Behind-Back Escape | Domantas Sabonis | 75 |
| Between-Legs Escape | Joel Embiid | 55 |
| Crossover Escape | Joel Embiid | 55 |
| Hesitation Escape | Paolo Banchero | 75 |
| Breakdown Combo | Wembanyama / Sengun / Paolo | 68 / 55 / 75 |
| In and Out | *(none — Basic/Normal/Pro only)* | — |

**Cheapest full big handle kit:** at **BH 55** you unlock Embiid/Jokic/KAT spins +
Embiid stepbacks. At **BH 68** add Wembanyama crossover/combo. At **BH 75** you get the
complete set (Paolo hesitations/escapes, Sabonis behind-back). So a point center with
**~68–75 Ball Handle** can equip a signature move in nearly every category — above the
Target build's fallback, right at its Gold tier. Guard moves (Curry, Kyrie, etc.) are
**hard height-locked** regardless of Ball Handle.
